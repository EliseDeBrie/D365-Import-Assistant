Matching & timing

How long to wait for a bound field to show up after a click (e.g. the Source data format dropdown after Add file, or the Entity name field after picking a format). If D365 is slow to render for you, raise this.

If you bind "entities grid row", the extension waits for a new row to appear there (up to this timeout) before starting the next file. Otherwise it just pauses for the "Pause between files" duration and assumes it's done. Defaults to 5 minutes because D365 warns that Excel imports can queue waiting for the Excel driver.
